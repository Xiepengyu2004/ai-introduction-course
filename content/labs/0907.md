# 2026.9.8 答疑

### 一、Python 编程基础与前置知识

1. **Python 零基础如何上手**：没学过 Python，编程基础较差，如何快速补齐完成作业所需的语法和常用库（如 NumPy、PyTorch 等）？是否有推荐的学习路径或资源？
2. **代码能力要求**：作业需要自己从头编写算法，还是主要运行/调试已有模型？对函数、类等 Python 高级特性掌握到什么程度？

### 二、环境配置与平台使用

1. **作业环境配置**：本地环境如何部署（如安装 Python、依赖库）？是否必须使用 Colab？能否完全在本地完成训练和调试？
2. **Kaggle 平台操作**：Kaggle 竞赛数据如何加载、导入导出？Kaggle Notebook 如何使用？作业是否涉及提交到 Kaggle 排行榜？
3. **谷歌服务访问困难**：无法正常创建谷歌账号、谷歌云盘调用报错，外网访问受限，有无替代方案（如国内镜像、离线数据集、本地 Jupyter）？

### 三、作业（Assignment）具体操作流程

1. **作业入口与结构**：整个作业的代码文件入口在哪里？需要修改哪些部分？目录结构是否有固定要求？
2. **提交内容与格式**：提交的压缩包（如 `学号_assignment1_1.zip`）中，Notebook 要保留完整运行输出还是清空后提交？生成的 `.npy` 文件是否必须由“最后一次从头运行”产生？
3. **实验报告要求**：报告是否有模板？使用中文还是英文？必须包含哪些部分（如理论推导、实验截图、结果表格、反思、参考文献）？大概多少页合适？基础实验（如 softmax 原理）是否需要写入报告？

### 四、评分与截止政策

1. **准确率门槛**：作业中标注的准确率阈值（如 `>0.33`、`>0.36`、`>0.5`）是硬性要求还是参考值？未达到会如何扣分？
2. **研究实验（45分）评分标准**：优化器对比、调参、初始化×激活等研究性实验，评分看重实验数量、图表丰富度，还是分析深度？有无往届优秀范例参考？
3. **截止时间政策**：“软截止（9/15）”和“硬截止（9/25）”的具体区别？逾期提交如何扣分？

### 五、课程学习与出勤

1. **课程重点**：本门课的学习重心是算法理论理解，还是代码实现能力？
2. **缺勤影响**：后续有约三分之一课时无法到堂，会对成绩或作业产生什么影响？有无补救措施？
