# 实验二：从 kNN 到 Softmax

本实验围绕两个问题展开：如何定义“相似”，以及如何通过数据学习分类边界。

## 核心任务

- 实现 kNN 的双循环和完全向量化距离；
- 使用 cross-validation 选择 `k`；
- 推导 Softmax loss 与梯度；
- 使用数值梯度检查实现；
- 比较训练成本、预测成本与准确率。

## 实验报告建议

不要只粘贴最终准确率。至少保留一次失败或不理想的实验，并说明你如何根据结果修改参数或代码。
