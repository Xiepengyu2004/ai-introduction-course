# 评分规则与成绩查询

## 评分原则

### 基础实验：

提交的时候保证notebook在Kaggle、Colab或者本地可以顺利执行一遍，保证存储了模型参数文件`.npy`，最终会通过少量测试样例自动化评判。

### 探究实验：

根据提交实验报告主观评定，综合个人思考深度（**更重要**），绘图，报告美观度（加分项）给分。

### 分数分布：

* 期末考试 (45%)
* 课程实验 (45%)

|    Assignment1    |   10%   |
| :---------------: | :-----: |
|  **Assignment2**  | **10%** |
|  **Assignment3**  | **10%** |
| **Final Project** | **15%** |

* 课程竞赛 (10%)

| **提交获得分数** | **80%** |
| :--------------: | :-----: |
|   **实验报告**   | **20%** |

### Soft 和 Hard DDL

* 在Soft DDL前提交奖励**单次实验总分**5%的分数
* **实践+竞赛部分汇总分数不超过55**

## 申请复核

成绩发布后 7 天内在QQ向助教提交复核申请，提供题号、原提交内容和具体疑问。复核可能导致分数上升、保持不变或下降。
