# 评分规则与成绩查询

## 评分原则

- 正确性：实现通过基础与边界测试；
- 方法：遵守向量化、数据划分等实验要求；
- 分析：能够使用实验结果支持结论；
- 规范：输出完整、图表清晰、按时提交。

## 查询个人成绩

请通过学校教学平台或课程指定的成绩系统查询。教师发布网站前，应把本页 front matter 中的 `externalUrl` 替换为真实的校内入口。

## 申请复核

成绩发布后 7 天内提交复核申请，并提供题号、原提交内容和具体疑问。复核可能导致分数上升、保持不变或下降。

> 请勿在 GitHub Issue 中发布学号、姓名、成绩截图或含个人信息的 notebook。
