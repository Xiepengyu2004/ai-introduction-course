# 欢迎学习《人工智能导论》

本课程面向第一次系统接触人工智能的大二本科生。我们会从问题表示、搜索与优化开始，逐步进入机器学习、神经网络和现代人工智能系统。

## 你将学到什么

- 用形式化方法描述一个智能问题；
- 理解训练集、验证集和测试集的作用；
- 使用 NumPy 实现基础分类算法；
- 阅读训练曲线并诊断欠拟合与过拟合；
- 对模型的能力、限制和社会影响保持批判性认识。

## 推荐学习循环

1. 课前阅读学习文档，记录不理解的概念。
2. 课堂上关注公式背后的直觉，而不只是结论。
3. 实验前先阅读验收标准，再开始编程。
4. 每次实验都保留运行输出和简短结论。
5. 遇到错误时先构造最小测试，而不是直接大规模训练。
