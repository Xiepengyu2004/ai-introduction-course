# 实验一：环境与数据

## 实验目标

- 能够在 Kaggle 中挂载课程 Dataset；
- 理解 `/kaggle/input` 与 `/kaggle/working` 的区别；
- 成功加载并可视化 CIFAR-10；
- 学会保存 notebook Version 和代码进度包。

## 验收标准

1. 输出训练集和测试集的 shape。
2. 每个类别至少展示一张图像。
3. 用一句话说明为什么测试集不能用于超参数选择。

## 常见问题

如果修改 `.py` 后 notebook 没有变化，请确认编辑的是 Working 下的可写副本，并重新运行 import 单元。
