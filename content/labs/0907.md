# 2026.9.8 答疑

### 一、Python 编程基础与前置知识

1. **Python 零基础如何上手**：没学过 Python，编程基础较差，如何快速补齐完成作业所需的语法和常用库（如 NumPy、PyTorch 等）？是否有推荐的学习路径或资源？

   答：我们已经用 `GPT5.6Sol`在**实验资源**板块生成了一份**最小入门手册**，可以通过这一章节的学习，掌握本次实验最需要的函数操作。同时也提醒大家：在AI时代，我们学习的方式也需要从传统方式转型，同学们考虑的更多是**Tradeoff**，权衡我需要带走什么知识什么能力和AI帮我完成哪些工作。

   提示词 Prompt参考：

   ```
   Users: 在实验资源板块增加一个markdown文档，因为这门课很多同学还没有学过python，帮我做一个最小化完成实验的python以及numpy教程，尽量简单清晰
   GPT-5.6: 已在“实验资源”板块新增：......
   ```

   比如我在遇到不知道怎么求一个`numpy.array`数组最大值下标的时候，我可以这样问AI：”numpy有什么函数可以完成返回一个`np.ndarray`最大值下标的操作呢“。AI会告诉你有**`numpy.argmax`**这个操作，并且举例说明基本用法。

   当然这只是一个例子，也许你不需要这么细粒度的问题，你完全可以让AI帮你完成整份作业，它甚至能够做到满分，但你在这个实验中学会的知识和带走的能力完全由你的Tradeoff决定。

2. **代码能力要求**：作业需要自己从头编写算法，还是主要运行/调试已有模型？对函数、类等 Python 高级特性掌握到什么程度？

   答：作业主要是以**补全TODO**的形式完成，整体的代码框架都已经给出，只需要按照实验指导一个一个**code block** 地完成就行。掌握程度也是完全由你自身决定，在还没有完全实现软件自动化的当下，AI已经能够写出非常规范、鲁棒、错误率低的代码，甚至都不需要人为核验。

   1. 如果**你想**在这次小小的实验中能够收获到一些学习python和它相关库的**体验感**，那你可以让AI为你写一份框架的注释，了解各个板块以及库的作用，至少在脑海里有一个初步的印象，numpy是用来干什么的，numpy有哪些函数等等。
   2. 如果**你想**成为一名**”Vibe Coder”**，那你可以借助自然语言编程的方式完成这份实验而跳脱具体代码细节，但你需要关注的是业务流程的实现是否达到预期：比如函数实现是否正确，端到端的结果是否正确。
   3. 当然还有更多的**你想**，只要你想的合理，大胆去做，课程和实验作业都不会为你绑上枷锁

### 三、作业（Assignment）具体操作流程

1. **作业入口与结构**：整个作业的代码文件入口在哪里？需要修改哪些部分？目录结构是否有固定要求？

   答：在实验网站的**课程作业-Assignment1.1**里面有提供具体指导，基础实验只需要把三个`.ipynb`跑通即可，进入到`.ipynb`会有实验指导具体**修改哪些部分**（ctrl+F 搜索TODO也可以找到），目录结构尽量按照提交格式，实际上1.1的基础实验也不需要额外创建什么python或者jupyter文件

2. **提交内容与格式**：提交的压缩包（如 `学号_assignment1_1.zip`）中，Notebook 要保留完整运行输出还是清空后提交？生成的 `.npy` 文件是否必须由“最后一次从头运行”产生？

   答：保留完整运行输出，但如果遇到争议我们还是会在分数复核阶段重新执行一遍你的notebook。`.npy`是模型权重的存放文件，需不需要从头运行生成，完全取决于你个人，如果没有添加随机因子、没有改变过会影响参数的变量，无论你执行代码多少遍都是相同的结果。

3. **实验报告要求**：报告是否有模板？使用中文还是英文？必须包含哪些部分（如理论推导、实验截图、结果表格、反思、参考文献）？大概多少页合适？基础实验（如 softmax 原理）是否需要写入报告？

   答：已经提供Stanford的Latex报告模板，使用中文完成实验报告，我们对实验报告的要求相对很低，这不是一门为难学生的课程，也不希望你们去卷非常漂亮的报告（AI比你更会写出漂亮的报告），**只要你讲清楚实验的过程，个人收获和自我思考（基础实验部分可以简单概括，重点是探究实验中你怎么设计实验，怎么分析结果，调控哪些变量等等）**，至于其它内容只是锦上添花，如果你追求完美，那当然欢迎你把它写成一份非常规范的报告。

### 四、评分与截止政策

1. **准确率门槛**：作业中标注的准确率阈值（如 `>0.33`、`>0.36`、`>0.5`）是硬性要求还是参考值？未达到会如何扣分？

   答：作业中标注准确率阈值的意思是如果你正确实现了这一部分的任务，预期是能够达到这个准确率的。如果没有达到，需要重新检查一下自己的实现是否正确。我们的评分跟这里的准确率不相关我们会额外设计样例。

2. **研究实验（45分）评分标准**：优化器对比、调参、初始化×激活等研究性实验，评分看重实验数量、图表丰富度，还是分析深度？有无往届优秀范例参考？

   答：看重实验的完整性以及逻辑的完整性，设计的实验和推导出的结论需要有逻辑上的关联，给出图表是一方面为了助教阅读起来更方便、另一方面说明你确实有完成这个实验，没有往届优秀范例。

3. **截止时间政策**：“软截止（9/15）”和“硬截止（9/25）”的具体区别？逾期提交如何扣分？
